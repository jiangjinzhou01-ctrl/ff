# 设计与交互系统

设计解读：面向学生、家长、校友与教师的公办学校网站重构，以可信的信息组织为基础，以编辑式排版和本校摄影表达“时间、探索与成长”。这是自定义编辑式设计，不声称使用某个国际机构的官方设计系统。

`DESIGN_VARIANCE: 6`，让章节构图不同但保持阅读秩序；`MOTION_INTENSITY: 4`，按用户新要求增加弹簧交互反馈，阅读区域保持安静；`VISUAL_DENSITY: 4`，首页保留空间，服务页面提高信息密度。

- 色彩：暖白 #F6F3ED、炭黑 #202424、深矿蓝 #172A30、石灰 #A9A59E、朱砂 #A14D40。全站统一浅色阅读主题，照片叠字使用定向遮罩。
- 字体：本地 Noto Sans CJK / Noto Serif CJK 重命名子集；文化标题使用宋体，信息、操作与正文使用黑体；西文年份使用系统 Arial。
- 形状：内容不做通用圆角卡片，按钮及资料提示使用直角；通过栅格、空白、细线和字号区分层次。
- 首页：摄影到达、巨型年份与原生滚动历史、跨栏校训、错落空间影像、体育成果的数字排版、编辑式报道、安静的招生邀请。
- 手机：首屏重新裁切，标题重新设定字号；历史改为纵向记录；摄影更改顺序；服务内容避免横向阅读；完整的独立移动菜单可展开、内部滚动与关闭。
- 动效：所有内容默认可见；IO 进入只作用于少量影像与校训文字。无滚动接管、循环动画或持续 scroll 监听；系统减少动态效果偏好禁用装饰动画与平滑滚动。
- 图片：本校实拍，不使用虚构校园或媒体照片的未授权转载。因缺少师生与赛事影像授权，体育以经核实的赛事实例和排版表达，课堂、艺术与社团影像明确待授权。

## 信息架构

首页 / 学校概况 / 教育教学 / 校园生活 / 新闻动态及六个分类 / 五篇报道详情 / 招生信息 / 党群与公开 / 联系我们 / 站内搜索 / 来源说明 / 404。另保留三条历史文章路由的静态跳转。

原首页、admissions.html、about.html、education.html、campus.html、news.html、sources.html 路由继续可用。旧文章入口转向对应 `/news/*.html`。

## 设计技能预检适配

用户明确要求的章节编号、滚动提示、真实摄影出处及指定暖白色板优先于通用技能的默认禁用项。无生成图；不为满足通用“必须生成资产”的规则虚构学校。所有审美取舍服从公办学校身份、无障碍与内容真实性。
