# 弹簧交互更新

本次按“保留公办学校的编辑式视觉，提升操作反馈”处理，设计差异 6、动态强度 4、内容密度 4。参考 iOS 的按压、阻尼与手势习惯，使用网页平台实现；不声称使用 Apple 原生动画系统，也不模拟设备震动或接管页面滚动。

## 反馈规则

| 场景 | 刚度 | 阻尼 | 质量 | 行为 |
| --- | ---: | ---: | ---: | --- |
| 按压 | 850 | 48 | 0.65 | 图标压缩到 90%，按钮到 96.5%，大幅影像与长行到 98.5% |
| 松手 | 480 | 25 | 0.65 | 轻微回弹后回到原尺寸 |
| 菜单与下拉 | 420 | 38 | 1 | 表面进入与中途反转；菜单通常约 400ms 结束 |
| 折叠栏 | 460 | 42 | 1 | 从当前高度连续转向新高度，结束后恢复自然布局 |

统一参数位于 `src/scripts/motion.ts`。Motion 14.8.0 的 mini 负责原生 Web Animations，spring 生成器计算曲线；构建按需提取，不包含 React 运行时。共享动效模块约 12.9KB，gzip 约 5.3KB，实际哈希与文件大小以构建输出为准。

- 按压：Pointer Events 事件委托覆盖动态搜索按钮。移动超过 10px、pointercancel、失去窗口焦点时释放反馈，不阻止触屏原生滚动。
- 菜单：原生 dialog 维护模态语义和焦点；顶部拖动区域提供阻力。短拖回位，向下超过 85px 或明确的快速下滑关闭；内容区域保留原生滚动。关闭、断点变化、页面离开和返回都释放背景锁定。
- 折叠：保留原生 details，键盘与无 JavaScript 情况仍可使用；动画期间内容高度可反转，收起内容暂时 inert，结束后移除临时尺寸。浏览器查找引起的原生展开会同步状态。
- 桌面导航：方向键循环访问子栏目，Home/End 到首尾，Escape 关闭并还原焦点；退出面板立即 inert，避免焦点落入正在消失的链接。
- 搜索：旧结果保留到新结果就绪，忙碌状态避免重复操作；新结果短暂依次进入。中文输入法确认组词后才查询；支持清除、真实错误重试、空结果与浏览器返回。
- 图库：PhotoSwipe 使用缩略图到大图的缩放过渡，保留库内触屏切换、双指缩放、关闭、说明与键盘行为。图片解码和入场结束后启用其图库快捷键。
- 阅读：支持浏览器原生跨文档 View Transition，有限淡入与 5px 位移；不支持的浏览器直接完成导航。
- 减少动态：首次加载和运行中更改均生效；弹簧立即到达最终状态，已启动的 WAAPI 动画完成，图库空间过渡关闭。无闲置动画循环；仅搜索真正等待时显示加载指示。

## 验证方法

`tests/motion_qa.py` 覆盖快速反转、拖动、手势取消、方向键、中文输入法、搜索保留、运行中减少动态与最终静止状态。`tests/browser_qa.py` 覆盖全站布局及既有服务。两者为可选 QA 脚本，运行站点不依赖 Python。

本地 Chromium 采样不等同于 iPhone 真机与 Safari 保证。浏览器网页不能调用 iOS 原生触感引擎；本次交付的是可操作的视觉与手势反馈。


## 2.2 · 双端交互与叙事反馈

- 首屏：照片缓慢收束、中文标题两行依次进入，约 1.1 秒内结束。章节标题、图片和新闻列表按阅读顺序进入，内容默认可见。
- 首页章节导览：手机与桌面共用七个锚点，当前章节和阅读进度随原生滚动更新。手机可横向触控选择。
- 校史：同一组三年份控件，提供点选、前后按钮、左右键/Home/End及触控左右滑动。年份与正文同步，手机不再固定显示1955。正文位移切换时保持完整对比度。
- 影像：首页照片直接开启与校园页共用的 PhotoSwipe，支持双指缩放、滑动、可见的前后按钮、键盘与关闭。原图及出处不变。
- 文章：桌面和手机都有阅读进度与真实的复制链接操作。
- 反馈：增加年份、导览、影像和故事入口的指针/触屏/键盘按压反馈；菜单和折叠操作继续支持中断。
- 减少动态：媒体查询在运行中切换时也立即完成动画，交互仍可使用；没有永久动画循环。

新增 `tests/parity_qa.py`：在320/360/390/768/1024/1440px实际执行交互对等检查。此为 Chromium 手机模拟，不声称进行了 Android 或 iOS 真机测试。

图库对展开期间的关闭请求保留队列，展开结束即关闭。对应回归脚本：`tests/gallery_interrupt_qa.py`。
